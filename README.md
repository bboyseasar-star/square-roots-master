# 👹 高校入試対策シリーズ ～大問2・数と平方根～

沖縄県立高校入試の確認済みの平方根出題形式だけを、過去問の本文・数値を転載せず、別数値のオリジナル問題として練習する静的Webアプリです。

- 10問、8問以上でクリア
- 出題根拠: H21、H23〜H25、H28、H30〜H31、R02〜R05で確認した平方根の出題形式
- 保存: このブラウザのlocalStorageに履歴だけを保存。学習履歴・答案・手書き内容は外部送信しません。
- 外部通信: 数式ライブラリとWebフォントの読込時に、各CDNへ通常のアクセス情報（IPアドレス、User-Agent、Referer等）が送信されます。接続先は`DEPENDENCIES.md`に記載しています。
- 問題画面では、ペン・部分消し・全消しを備えた手書きメモを利用できます。手書き内容は保存・送信されません。
- ローカル確認: 静的サーバーで`index.html`を開いてください。

公開・配布・Git操作は、この成果物に含みません。

このアプリは沖縄県および沖縄県教育委員会の公式アプリではありません。

## 出題形式の照合記録

過去問は形式確認だけに使用し、問題文・数値・解説は転載していません。

|技能タグ|確認した年度・形式|アプリでの独自生成|
|---|---|---|
|`num.root_calc`|H25、R02〜R05の根号を含む計算|係数・根号内をseedで変更|
|`num.simplify_root`|H25の根号を整理して計算する形式|平方因数4・9と平方因数を持たない数を組合せ|
|`num.rationalize`|H24の分母の有理化|分子・分母の根号内をseedで変更|
|`num.compare`|H21の自然数の個数、H23・H31の最も近い自然数、H24の大小、R05の根号間の自然数|平方数境界が曖昧にならない候補から生成|
|`num.signed_power`|H28・R03の平方根に関する正誤|数値と選択肢を独自生成|
|`num.transfer`|H30の整数となる最小の自然数|根号内の係数をseedで変更|
|`num.classify`|R04の有理数・無理数分類|完全平方数・非平方数・整数・分数を独自生成|
